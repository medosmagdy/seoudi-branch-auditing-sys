# صفحة الملخص وأسماء ملفات التقارير — 28 أكتوبر 2026

- ترتيب الملخص: ثلاث بطاقات للنتيجة، ثم نتائج الأقسام، ثم الخصومات العامة، ثم إجراءات الاعتماد والتصدير.
- النتيجة النهائية لها تنسيق مستقل عن البار العلوي. جدول الأقسام قابل للتمرير على الموبايل، وحقول الخصم لها أسماء واضحة.
- النص يوضح أن التوصيل منفصل في الفروع العادية ومشمول في الدارك ستورز؛ محرك الحساب لم يتغير.
- اسم الملفات موحد للـPDF من الملخص والتقرير، والإكسيل بالمعادلات، والتقارير التي يولدها المستخدم لاحقًا.
- أمثلة: CityStars FS Audit Report 26-10-2026.pdf وCityStars GHP Audit Report 26-10-2026.xlsx وSheraton FSMS Audit Report Q3-2026.pdf.
- تاريخ FS وGHP بصيغة يوم-شهر-سنة. كوارتر FSMS مشتق من تاريخ الأوديت، وليس تاريخ التحميل.
- اسم الفرع الإنجليزي يأتي من branches.name_en؛ إذا لم يوجد يُستخدم الاسم المسجل. أسماء سيتي ستارز وشيراتون لها تهجئة معروفة للأمثلة. لا ترجمة آلية لباقي الفروع.
- قراءة الاسم الإنجليزي وكود نوع الأوديت تستخدم أعمدة موجودة بالفعل؛ لا تغيير لبيانات أو مخطط قاعدة البيانات، ولا SQL مطلوب.
- لا تغيير للدرجات أو الخصومات أو صلاحيات التعديل أو سلوك N/A. المعاينة البصرية الفعلية داخل المتصفح تبقى مطلوبة في البريفيو.
